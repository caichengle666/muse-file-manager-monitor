## v1.4 — 2026-10-03（修复系统启动时间漂移）

- "系统启动时间"此前每次采样重新计算导致漂移（连续采样三个值各不相同）；现优先读 `/proc/stat` 的 `btime`，不可用时用高精度 `/proc/uptime` 回算，并在进程内缓存，后续轮询不再重算
- 实测验证：连续三次 `getSystemSnapshot` 采样，`bootedAt` 完全一致（`2026-10-03T03:10:04.000Z`）

## v1.3 — 2026-10-03（服务重启记录）

- 监控页新增"服务重启记录"：累计重启次数、上次重启时间、本次启动时间、本次已运行时间，本地时间秒级显示，随 3 秒轮询刷新（`getSystemSnapshot` 返回 `restartCount` / `lastRestartAt` / `bootedAt`）
- 数据持久化：新增数据库表，重启后不清零；实测终止 worker 再拉起，计数 1→2、前次启动时间保留
- 已知局限：当前运行时没有"服务启动前"钩子，登记是懒登记（发生在首次快照请求时，而非进程真正启动瞬间）；多 worker 部署下同一服务实例可能被重复计数

## v1.2 — 2026-10-03（私有模式改映射真实目录）

- 私有模式不再用 SQLite `workspace_items` + blob 虚拟存储，改为直接映射构件沙盒内的真实目录 `data/private`，与系统/工作区/构件三页签共用同一套真实文件操作逻辑（浏览、预览、编辑保存、新建、上传、下载、移动/重命名、永久删除）
- 位置透明：界面显示该目录的绝对路径；面包屑根节点改叫"私有"
- 文件夹补上可达的删除入口（含手机端）；原有文件夹"123"已迁移保留
- 删除改用"隔离改名 → 真删 → 结果核验 → 失败恢复"流程，保存沿用临时文件原子替换，杜绝"报错但东西没了"的不一致状态
